# Usability Testing & Analysis

## Objective
Conduct usability testing on a digital product and analyze the results.

## Product Tested
E-Healthcare Mobile Application

## Activities Performed
- Prepared usability test plans
- Created test scenarios
- Conducted user testing sessions
- Collected observations and feedback
- Analyzed results and suggested improvements

## Tools Used
- Figma
- Google Forms
- GitHub

## Outcome
Identified usability issues and proposed design improvements to enhance the user experience.
