# Usability Test Plan

## Product
E-Healthcare Mobile Application

## Purpose
To evaluate the usability and effectiveness of the application.

## Test Objectives
1. Measure ease of navigation.
2. Evaluate task completion rate.
3. Identify usability issues.
4. Collect user feedback.

## Participants
5 users with basic smartphone knowledge.

## Testing Method
Moderated usability testing.

## Duration
15–20 minutes per participant.
